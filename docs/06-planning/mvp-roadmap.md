# Roadmap MVP

**Status:** Final.

| Tahap | Hasil | Estimasi |
| --- | --- | --- |
| 0. Fondasi | Monorepo, Compose, database, RustFS, autentikasi RUAS, kelas | 3–5 hari kerja |
| 1. Materi | Editor blok, upload, status modul, halaman baca murid | 4–6 hari kerja |
| 2. LKPD | Editor tujuh blok, autosave, penilaian otomatis | 6–9 hari kerja |
| 3. Penugasan | Jadwal, kelas tujuan, pengumpulan, penilaian manual, exit ticket | 4–6 hari kerja |
| 4. Bukti dan rilis | Activity log, presensi, laporan, ekspor, konten awal, uji beban | 4–6 hari kerja |

Total estimasi: **21–32 hari kerja paruh waktu**. Estimasi bergantung pada ruang
lingkup yang tetap dan mekanisme autentikasi RUAS yang dapat dibuktikan.

## Urutan penerimaan

Tahap berikutnya tidak menggantikan tahap sebelumnya. Rekap dibangun setelah
data aktivitas, pengumpulan, penilaian, dan exit ticket tersedia.
